* Die Idee in einem Absatz

Ein Taschenrechner stellt Rechnen als Ressource bereit. Niemand nennt ihn intelligent, und trotzdem baut eine kreative Person darauf auf. Ich glaube, dass sich Intelligenz und Kreativität genauso aufteilen: Es gibt Ressourcen am Boden, die die kreative Person auf eine höhere Ebene heben. Ein Sprachmodell ist so eine Ressource, eine algorithmische Operation mit natürlicher Sprache als Ein- und Ausgabe. Es ist unscharf, wo ein Taschenrechner exakt ist, weil es auf hochdimensionalen Daten arbeitet, aber es bleibt algorithmisch. Meine Position: Das Modell allein ist keine kreative Person, so wenig wie ein Taschenrechner. Kreativität wäre eine Eigenschaft der Organisation, in der es steckt.
