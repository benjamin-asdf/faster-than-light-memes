* The idea in one paragraph

A calculator produces calculation as a resource. Nobody calls it intelligent, and it is still something a creative person builds on. I think intelligence and creativity split the same way: there are resources on the ground that lift the creative person to a higher level. A language model is such a resource, an algorithmic operation with natural language as input and output. It is fuzzy where a calculator is exact, because it works on high-dimensional data, but it is still algorithmic. My position: the model alone is no creative person, just as a calculator is not. Creativity would be a property of the organization it sits in.
